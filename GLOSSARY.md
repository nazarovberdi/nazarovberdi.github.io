# Portfolio

The personal site of Nazarov Berdi, a frontend engineer. It exists to get him hired: the content shows his work, and the motion itself is proof of craft.

## Content

**Project**:
One piece of public work shown in Work: a Product or Open source, always with something a visitor can open.
_Avoid_: Repo, item, card, client work (employer work is Experience, never a Project)

**Experience**:
Paid work for an employer, described in About and never shown as a Project.
_Avoid_: Client work, job, professional project

**Product**:
A Project Berdi built and runs himself, live for real users.
_Avoid_: Side project, pet project, app

**Open source**:
A Project whose value is its public code.
_Avoid_: Library, repo, OSS contribution

**Work**:
The home section that presents every Project.
_Avoid_: Projects section, selected work, portfolio grid

**Preview**:
The visual shown for a Project when it is focused: a screenshot of its live site, or a Poster.
_Avoid_: Thumbnail, cover, card image

**Poster**:
A typographic Preview made for a Project that has no live site to capture.
_Avoid_: Placeholder, fallback image

**About**:
The home section that introduces the person: portrait, short bio and skills.
_Avoid_: Toolbox, bio section, skills section

**Writing**:
The articles published on the site, and the section that lists them.
_Avoid_: Blog (in copy; it survives only in URLs), posts, articles section

**Case study**:
A piece of Writing about one Project: the problem, the decisions and what Berdi would change. Its Work row links to it.
_Avoid_: Write-up, deep dive, project page

**Contact footer**:
The closing block with the email and social links, uncovered from beneath the page as it ends.
_Avoid_: Contact section, footer (alone)

## Motion

**Line mask**:
Text that rises into view line by line from behind an invisible edge.
_Avoid_: Text reveal, fade-up

**Split hover**:
On hover, a label rolls away and an identical copy rolls in to replace it.
_Avoid_: Text swap, HoverLabel effect

**Mask reveal**:
An image or block uncovered by a moving clipped edge.
_Avoid_: Wipe, clip animation

**Panel transition**:
A solid panel that sweeps across the screen to hide one page and uncover the next.
_Avoid_: Page wipe, route animation

**Pixel toggle**:
The theme switch, where the screen dissolves through a grid of blocks into the other theme.
_Avoid_: Pixel transition (that name is for page changes, which this site does not use)
